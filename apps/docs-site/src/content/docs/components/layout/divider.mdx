---
title: Divider
description: 1px theme-colored line. Horizontal or vertical, with optional inset.
---

## Install

```sh
npx stylesheet-ui add divider
```

## Usage

```tsx
import { Divider } from "@/components/ui/divider";

<Divider />
<Divider inset="2xl" />
<Divider orientation="vertical" />
```
